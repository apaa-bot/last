2. Ganti nama, teks, dan foto.

4. Rename hasilnya menjadi slide1.jpg, slide2.jpg, ... slide9.jpg.
5. Masukkan file-file tersebut ke folder website/canva_ppt_mode/slides.
6. Upload folder canva_ppt_mode ke GitHub lalu hubungkan ke Vercel.
Tidak perlu mengedit HTML/CSS/JS.
